# Audit on Financial Statements — Differentiated Lesson Plan

**Course:** Audit  
**Topic:** Audit on Financial Statements  
**Target Learners:** Diploma in Accountancy, TVET Polytechnic Malaysia  
**Duration:** 2 Hours  

## Philosophy
> "Different learners, different support — but the same destination."

## What's Inside

| File | Description |
|------|-------------|
| `audit-lesson-plan.docx` | Full differentiated lesson plan (Sections A–N) |

## Lesson Structure

| Stage | Duration | Activity |
|-------|----------|----------|
| ENGAGE | 10 min | Real-life audit situation |
| EXPLORE | 15 min | Prior knowledge activation |
| EXPLAIN | 25 min | Key concepts — 7 financial statement items |
| APPLY | 35 min | 3-level differentiated activities |
| AUDIT CHALLENGE | 20 min | Mini audit case (Syarikat Logistik Pantas) |
| ASSESS | 10 min | Formative assessment |
| REFLECT | 5 min | Exit ticket |

## 3 Levels of Support

| Level | Label | For Students Who... |
|-------|-------|---------------------|
| Level 1 | BUILD MY CONFIDENCE | Need simple language, examples, step-by-step guidance |
| Level 2 | LET ME APPLY IT | Ready to apply in scenarios and working papers |
| Level 3 | CHALLENGE MY AUDITOR THINKING | Ready for professional judgement and case analysis |

## Financial Statement Items Covered
1. Revenue
2. Expenses
3. Current Assets (Cash, Receivables, Inventory)
4. Non-Current Assets (PPE)
5. Current Liabilities (Trade Payables)
6. Non-Current Liabilities (Loans)
7. Equity
